# Матрица стейкхолдеров: трансформация Fast Cargo

**Основа:** раздел «Кросс-функциональные требования» (EDI, IoT, CRM, критерии 1–4, метрики ×10 / 99,95% / ≤ 5 с) и целевая архитектура из [Task1](../Task1/transformation_plan.md).

**Приоритеты:**
- **Critical (Must)** — явное условие сделки (кросс-функциональные требования, критерии 1–4, метрики), требование закона, непрерывность отгрузок или право вето ЛПР. Без этого проект блокируется.
- **Medium (Should)** — существенно для успеха, но есть обходной путь.
- **Low (Nice)** — улучшение, уходит в бэклог.

**Важность и срочность не смешиваются:** приоритет — это важность, а срок вынесен в отдельную колонку «Когда нужно». Внутри Critical строки отсортированы по сроку.
